# 1. flow context 如何构造？

这是最重要的问题。

你现在有几个选择：

---

## A. Temporal Neighbor（最简单）

按时间排序：

```text
previous K flows
current flow
next K flows
```

优点：

* 最容易实现
* 最符合 proposal
* sequence natural

缺点：

* unrelated flows 太多
* context noise 大

---

## B. Same-host Context（更合理）

例如：

```text
same src IP
same dst IP
same session
```

构造 context。

这其实更像：

> communication context transformer

优点：

* security semantic 更强
* 更符合 attack propagation

缺点：

* preprocessing 更复杂

---

## C. Graph-inspired Context（最强）

Stage-II 输入不是简单 sequence：

而是：

```text
host interaction neighborhood
```

例如：

* same src
* same dst
* same subnet
* temporal adjacency

这种已经接近：

> graph transformer

这个会很强，但复杂度会上升很多。

---

# 我建议你现在先做：

# Temporal + Same-host Hybrid

例如：

```text
context = nearby flows
filtered by shared endpoint
```

因为：

纯 temporal context 很容易无意义。

但完全 graph 化又太大。
