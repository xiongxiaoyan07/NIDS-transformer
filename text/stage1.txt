## 五、潜在改进点

基于这个数据处理流程，你的Class 1 F1偏低可能与以下因素有关：

1. **特征区分度**: 85维特征中可能有冗余或无信息特征
2. **时序信息利用**: 仅使用`head`策略可能丢失关键包
3. **统计特征**: 流级特征已经包含了统计信息，但可能不够精细
4. **包间关系**: Transformer应该能捕捉，但需要足够的数据和模型容量

* 包方向序列特征（dir_seq）

## 二、模型创建详解 (`model.py`)

### 🔹 **架构总览**

```
输入: [B, 40, 85] 包序列
  │
  ├── RecordLevelProjection   [B, 40, 85] → [B, 40, 128]
  │     └── build_mlp: Linear(85, 128)
  │
  ├── TimeAwareEncoding       [B, 40, 128] → [B, 40, 128]
  │     ├── Positional Encoding (sinusoidal, 不可训练)
  │     │     PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
  │     │     PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
  │     │
  │     └── Time Encoding (可训练MLP)
  │           time_mlp: log(1+iat) → Linear(1,128) → GELU → Linear(128,128)
  │
  ├── TransformerEncoder      [B, 40, 128] → [B, 40, 128]
  │     ├── Layer 1: MultiHeadAttention(8 heads) + FFN(128→512→128)
  │     ├── Layer 2: MultiHeadAttention(8 heads) + FFN(128→512→128)
  │     └── Layer 3: MultiHeadAttention(8 heads) + FFN(128→512→128)
  │     (使用 src_key_padding_mask 忽略padding位置)
  │
  ├── AttentionPooling        [B, 40, 128] → [B, 128]
  │     └── 学习每个包的重要性权重，加权求和
  │
  └── Classifier              [B, 128] → [B, 2]
        ├── LayerNorm(128)
        ├── Linear(128, 128) + GELU + Dropout(0.1)
        ├── Linear(128, 64)  + GELU + Dropout(0.06)
        ├── Linear(64, 32)   + GELU + Dropout(0.04)
        └── Linear(32, 2)
```

### 🔹 **关键组件详解**

#### **1. RecordLevelProjection**

```python
class RecordLevelProjection(nn.Module):
    def __init__(self, input_dim=85, d_model=128, dropout=0.2):
        # 简单线性投影：85维 → 128维
        self.proj = nn.Linear(85, 128)
    
    def forward(self, x):  # x: [B, 40, 85]
        return self.proj(x)  # → [B, 40, 128]
```

#### **2. TimeAwareEncoding**

```python
class TimeAwareEncoding(nn.Module):
    def forward(self, e, time_log):
        # e: [B, 40, 128], time_log: [B, 40]
        
        # Step 1: 添加位置编码 (让模型知道包的顺序)
        out = e + self.pe[:, :seq_len, :]  # sinusoidal PE
        
        # Step 2: 添加时间编码 (让模型知道包之间的时间间隔)
        time_emb = self.time_mlp(time_log.unsqueeze(-1))  # [B, 40, 128]
        out = out + time_emb
        
        return self.dropout(out)
```

**为什么需要时间编码？**

* 攻击流量和正常流量的包间隔模式不同
* 例如：DDoS攻击可能有非常均匀的包间隔

#### **3. TransformerEncoder**

```python
# 配置: num_layers=3, nhead=8, d_model=128, dim_feedforward=512
layer = nn.TransformerEncoderLayer(
    d_model=128,
    nhead=8,           # 8个注意力头，每个处理 128/8=16 维
    dim_feedforward=512,  # FFN扩展比: 512/128=4x
    dropout=0.2,
    activation="gelu",
    batch_first=True,
    norm_first=True,   # Pre-LN: LayerNorm → Attention → Residual
)

self.encoder = nn.TransformerEncoder(layer, num_layers=3)
```

**Pre-LN vs Post-LN:**

```
Pre-LN (norm_first=True):   x + Attention(LN(x))     ← 更稳定
Post-LN (norm_first=False): LN(x + Attention(x))     ← 传统方式
```

#### **4. AttentionPooling**

```python
class AttentionPooling(nn.Module):
    def forward(self, h, mask):
        # h: [B, 40, 128], mask: [B, 40]
        
        # 计算每个包的注意力分数
        attn_weights = self.attention(h).squeeze(-1)  # [B, 40]
        
        # 将padding位置的分数设为极小值
        attn_weights = attn_weights.masked_fill(~mask, -1e9)
        
        # Softmax归一化
        attn_weights = torch.softmax(attn_weights, dim=-1)  # [B, 40]
        
        # 加权求和
        z = (h * attn_weights.unsqueeze(-1)).sum(dim=1)  # [B, 128]
        return z
```

**与平均池化的对比:**

```python
# 简单平均池化
z_avg = h.sum(dim=1) / mask.sum(dim=1, keepdim=True)

# 注意力池化 (当前使用)
z_attn = attention_pool(h, mask)  # 模型学习哪些包更重要
```

## 三、损失函数详解 (`losses.py`)

### 🔹 **FocalLossWithLabelSmoothing**

这是一个**三合一**的损失函数：

```python
class FocalLossWithLabelSmoothing(nn.Module):
    """
    结合三个技术：
    1. Focal Loss: 关注困难样本
    2. Label Smoothing: 防止过拟合
    3. Class Weights (alpha): 处理类别不平衡
    """
    def forward(self, inputs, targets):
        # inputs: [B, 2] (logits)
        # targets: [B] (0 or 1)
        
        # Step 1: 计算softmax概率
        probs = softmax(inputs)  # [B, 2]
        
        # Step 2: 获取真实类别的概率
        probs_gt = probs[targets]  # [B]
        
        # Step 3: 计算focal weight
        # 如果模型很自信 (probs_gt≈1)，权重≈0 → 降低简单样本的影响
        # 如果模型不自信 (probs_gt≈0.5)，权重≈0.25 → 关注困难样本
        focal_weight = (1 - probs_gt) ** gamma  # gamma=1.5
        
        # Step 4: 应用类别权重
        # alpha = [0.5008, 0.4992] (因为数据几乎平衡)
        focal_weight *= alpha[targets]
        
        # Step 5: 标签平滑交叉熵
        # 原始标签: [0, 1] → 平滑后: [0.025, 0.975] (smoothing=0.05)
        ce_loss = cross_entropy(inputs, targets, label_smoothing=0.05)
        
        # Step 6: 组合
        loss = (focal_weight * ce_loss).mean()
        return loss
```

**损失函数的数学形式:**

```
Loss = Σ (1 - p_t)^γ * α_t * CE(p_t, y_smoothed)

其中:
  p_t: 真实类别的预测概率
  γ: focal参数 (1.5)
  α_t: 类别权重 (≈0.5, 因数据平衡)
  y_smoothed: 标签平滑后的目标
```

### 🔹 **`train_model()` 完整流程**

```python
def train_model(model, loaders, cfg, out_dir, device):
    # ============ 初始化 ============
    # 1. 计算类别权重
    train_labels = collect_train_labels(loaders["train"])  # [13511, 13557]
    alpha = [0.5008, 0.4992]  # 几乎相等，数据平衡
    
    # 2. 创建损失函数
    criterion = FocalLossWithLabelSmoothing(
        alpha=alpha,          # 类别权重
        gamma=1.5,            # focal gamma
        label_smoothing=0.05  # 标签平滑
    )
    
    # 3. 优化器
    optimizer = AdamW(lr=0.0005, weight_decay=0.0001)
    
    # 4. 学习率调度器
    scheduler = SequentialLR(
        LinearLR(start_factor=0.1, total_iters=10),    # 预热10个epoch
        CosineAnnealingLR(T_max=490, eta_min=5e-6)     # 余弦衰减
    )
    
    # ============ 训练循环 ============
    for epoch in range(1, 501):
        # Step 1: 训练一个epoch
        train_loss = _train_one_epoch(model, train_loader, optimizer, criterion)
        
        # Step 2: 更新学习率
        scheduler.step()
        
        # Step 3: 验证
        val_metrics = evaluate_model(model, val_loader, criterion)
        
        # Step 4: 检查是否是最佳模型
        if val_metrics['f1_label1'] > best_score:
            best_score = val_metrics['f1_label1']
            torch.save(model.state_dict(), 'best_model.pt')
        else:
            # Early stopping (patience=30)
            if no_improvement >= 30:
                break
    
    # ============ 后处理 ============
    # 1. 加载最佳模型
    model.load_state_dict(best_checkpoint)
    
    # 2. 阈值搜索
    best_threshold = find_optimal_threshold(model, val_loader)
    # → 找到使F1最大的阈值: 0.70
    
    # 3. 测试集评估
    test_metrics = evaluate_model(
        model, test_loader, 
        criterion=CrossEntropyLoss(),  # 使用标准CE评估
        threshold=0.70                 # 使用最优阈值
    )
```

### 🔹 **`_train_one_epoch()` 详解**

```python
def _train_one_epoch(model, loader, optimizer, criterion, device):
    model.train()
    total_loss = 0
    
    for batch in loader:  # batch = {x, time, mask, label}
        # 1. 数据移到GPU
        x    = batch["x"].to(device)     # [64, 40, 85]
        t    = batch["time"].to(device)   # [64, 40]
        mask = batch["mask"].to(device)   # [64, 40]
        y    = batch["label"].to(device)  # [64]
        
        # 2. 前向传播
        optimizer.zero_grad()
        logits = model(x, t, mask)  # [64, 2]
        
        # 3. 计算损失
        loss = criterion(logits, y)  # scalar
        
        # 4. 反向传播
        loss.backward()
        
        # 5. 梯度裁剪 (防止梯度爆炸)
        torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
        
        # 6. 参数更新
        optimizer.step()
        
        total_loss += loss * batch_size
    
    return total_loss / total_samples  # 平均损失
```

* **Cosine Annealing**: 周期性降低学习率，帮助跳出局部最优
