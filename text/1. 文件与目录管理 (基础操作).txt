1. 文件与目录管理 (基础操作)
这是你每天在终端中移动和管理 PCAP 文件最常用的命令。

ls (List)：列出当前目录下的文件。

ls -l：查看详细信息（权限、大小、修改时间）。

ls -a：显示隐藏文件（以 . 开头的文件）。

cd (Change Directory)：切换目录。

cd ..：返回上一级。

cd ~：回到用户家目录。

pwd (Print Working Directory)：告诉你当前位于哪个文件夹，防止迷路。

mkdir (Make Directory)：创建新文件夹。如 mkdir pcaps。

rm (Remove)：删除文件。

rm -rf <文件夹>：危险命令！ 递归强制删除整个文件夹。使用前请三思。

cp (Copy) & mv (Move)：复制和移动/重命名文件。

2. 文件内容查看与编辑
在处理特征提取脚本或查看日志时必不可少。

cat：一次性显示整个文件内容。适合小文件。

less：分页查看大文件。按 Space 翻页，按 q 退出。处理成千上万行的 CSV 很有用。

tail：查看文件末尾。

tail -f /var/log/syslog：实时监控日志更新，非常适合观察 IDS 告警。

nano / vim：命令行文本编辑器。

nano 简单易用，适合新手。

vim 功能强大但有学习曲线。

3. 系统监控与进程管理
当你运行复杂的机器学习模型时，需要监控 CPU 和内存占用。

top / htop：查看系统资源占用排行榜。

推荐安装 htop (sudo apt install htop)，它有更直观的彩色界面和滚动条。

df -h：查看磁盘剩余空间。PCAP 文件通常很大，要经常检查磁盘是否爆满。

free -m：查看内存（RAM）使用情况。

ps aux：列出系统所有正在运行的进程。

kill -9 <PID>：强制关闭某个卡死的程序（PID 是进程 ID）。

4. 网络相关 (你的核心领域)
既然你在做网络流量分析，这些命令是你的“眼睛”。

ip a：查看本机 IP 地址和网卡信息。

ping <IP/域名>：测试网络连通性。

netstat -tuln：查看当前系统开启了哪些端口。

tcpdump：最强大的命令行抓包工具。

sudo tcpdump -i eth0 -w output.pcap：直接从网卡 eth0 抓取流量并保存为 PCAP。

5. 权限管理
Linux 是权限严苛的系统。

sudo：以管理员（Root）身份执行。

chmod：修改文件权限。

chmod +x script.sh：让一个脚本变得“可执行”。

chown：修改文件的所有人（Owner）。

6. 搜索与过滤 (高效进阶)
当你需要从几万行流量数据中找特定内容时：

grep：文本搜索神器。

grep "192.168.1.1" traffic.csv：从 CSV 中筛选出所有包含该 IP 的行。

find：在文件夹里找文件。

find . -name "*.pcap"：找出当前目录下所有的 PCAP 文件。

| (管道符)：将一个命令的输出传给另一个命令。

ls -l | grep "pcap"：列出文件，但只显示名字里带 pcap 的。
