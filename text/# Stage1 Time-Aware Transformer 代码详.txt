### 2.3 训练/验证/测试 划分：`splits.py`

支持两种划分方式：

#### a) 分层随机划分 `stratified_train_val_test_split()`

#### b) 时序划分 `chronological_train_val_test_split()` ⭐

```python
# 核心思想：
# train = 最早 70% 时间窗口
# val   = 中间 10% 时间窗口
# test  = 最新 20% 时间窗口

# 边界优化：在理论边界附近搜索，平衡 label=1 的分布
b1, b2 = _choose_chronological_boundaries_with_label_balance_fast_stride(
    labels, nominal_b1, nominal_b2, ...
)
```

**时序划分的边界搜索算法**（分块加速）：

```python
def _choose_chronological_boundaries_with_label_balance_fast_stride():
    """
    目标：保持时序连续性的前提下，平衡各 split 的正样本比例
    
    评分函数：
    score = 10.0 * label_balance_score    # 标签平衡性（主要权重）
          + 1.0 * size_score              # 划分比例偏差
          + 5.0 * missing_positive_penalty # 惩罚缺失正样本
    
    优化：分块向量化搜索 + stride 采样
    """
```

**设计权衡**：

| 特性    | 分层随机划分   | 时序划分        |
| ----- | -------- | ----------- |
| 时序保真度 | ❌ 完全打乱   | ✅ 严格连续      |
| 标签平衡  | ✅ 精确分层   | ⚠️ 近似平衡     |
| 适用场景  | 独立采样的数据集 | 连续抓包 / 真实流量 |

## 三、模型架构详解：`model.py`

### 3.1 组件层次

```

│   └── [Linear] or [MLP]      # 可配置 MLP

│   ├── Linear → Tanh → Linear → Softmax
```

### 3.2 Time-Aware Encoding ⭐ 核心创新

```python
class TimeAwareEncoding:
    """
    论文公式 6-7 的实现：
    
    TE(pos, 2j)   = sin((pos + p) / 10000^(2j/d_model))
    TE(pos, 2j+1) = cos((pos + p) / 10000^(2j/d_model))
    
    其中 p = log(1 + Σ(time_intervals) + α)
    """
```

**四种编码模式**：

| use_pos | use_time | 行为                             |
| ------- | -------- | ------------------------------ |
| True    | True     | **Full Time-Aware**: TE(pos+p) |
| True    | False    | **Position Only**: 传统 PE       |
| False   | True     | **Time Only**: TE(p)，无位置索引     |
| False   | False    | 无编码                            |

**时间特征计算**：

```python
def _compute_time_feature(self, time_log):
    # 反推原始间隔：exp(log1p(x)) - 1
    time_intervals = torch.expm1(time_log)
    # 累积求和 + 平滑
    cumulative_time = torch.cumsum(time_intervals, dim=1)
    p = torch.log(1.0 + cumulative_time + self.alpha)
    return p
```

**设计考量**：

* `alpha = 1e-7`：平滑因子，防止 log(0)
* `expm1` / `log1p`：数值稳定的反变换
* 预计算 `div_term` 和 `position`，推理时只计算 `p`

### 3.3 三种融合方案对比

```python
# 方案A：Flow 特征拼接到每个 Packet
# - x_i,t = [packet_features; flow_features_tiled]
# - flow 信息通过 Transformer 的 self-attention 参与包间交互

# 方案B：仅 Packet 特征
# - x_i,t = [packet_features]
# - 最简单的方案，作为 baseline

# 方案C：分层特征注入（gated 融合） ⭐
# - Packet 通过 Transformer → z_packet
# - Flow 通过 FlowFeatureEncoder → z_flow
# - z_final = gate * z_packet + (1-gate) * z_flow
```

**方案C 的 Gated 融合**：

```python
class FlowFusion:
    def forward(self, pooled, flow_encoded):
        if self.fusion_method == "gated":
            concat_feat = torch.cat([pooled, flow_encoded], dim=-1)
            gate = self.gate(concat_feat)  # [B, d_model], ∈ [0,1]
            fused = gate * pooled + (1 - gate) * flow_encoded
            return self.post_gate(fused)
```

### 3.4 Attention Pooling（替换简单 Mean Pooling）

```python
class AttentionPooling:
    def forward(self, h, mask):
        attn_weights = self.attention(h).squeeze(-1)     # [B, L]
        attn_weights = attn_weights.masked_fill(~mask, -1e9)
        attn_weights = torch.softmax(attn_weights, dim=-1)
        z = (h * attn_weights.unsqueeze(-1)).sum(dim=1)  # [B, D]
        return z
```

**优于 Mean Pooling**：

* 模型自动学习哪些包更重要
* 对填充位置正确忽略（mask 处理）
* 可解释性：可以可视化注意力权重

### 4.1 损失函数：`losses.py`

```python
class FocalLossWithLabelSmoothing:
    """
    结合三个技术：
    1. Focal Loss：降低易分类样本的权重
    2. Label Smoothing：防止过拟合
    3. Class Alpha：类别平衡权重
    """
    def forward(self, inputs, targets):
        # 1. Focal weight
        probs_gt = softmax(inputs)[targets]
        focal_weight = (1 - probs_gt) ** self.gamma
        
        # 2. Alpha weight
        alpha_weight = self.alpha[targets]
        
        # 3. Cross-entropy with label smoothing
        ce_loss = F.cross_entropy(inputs, targets, 
                                  label_smoothing=self.label_smoothing)
        
        return (focal_weight * alpha_weight * ce_loss).mean()
```
